# kuto-nanidasu

![KUTO Logo](src/assets/logo.avif)

A web application that provides the "Type Diagnosis" from Tactical Challenge (PvP).

You can try it out at:

https://1m-lcei.github.io/kuto-nanidasu/


## `kuto-nanidasu`?

`kuto` is an abbreviation for Kivotos United Tactical Olympiad, and this name can be seen in the content's introductory artwork.

`nanidasu` means "What do you put out?".
